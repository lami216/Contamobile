## الإجراءات المستقلة

- حذف السجل يخفي سجل الإدارة فقط؛ لا يلغي التفعيل أو يغيّر مدته. لا يعيد اتصال الهاتف السجل المحذوف تلقائيًا.
- إلغاء التفعيل يقفل الوصول بعد استلام قرار موقّع، ويحافظ على بيانات المحل والسجل.
- الحظر يلغي التفعيل ويمنع تفعيل الهاتف من جديد حتى رفع الحظر. يبقى في قائمة المحظورين حتى بعد حذف سجله العادي، مع آخر تفعيل ملغى.
- رفع الحظر يسمح بمراجعة تفعيل جديد صراحةً؛ لا يعيد التفعيل القديم تلقائيًا.
- إدخال كود الجهاز في كونتا تولز يستلزم ظهور مفتاح الهاتف المثبت وإثباته ومراجعته. الكود العام وحده لا يمنح صلاحية التفعيل أو تغيير هوية الجهاز.

قرارات الإدارة لا تمس قاعدة المحاسبة أو الحسابات أو كلمات المرور أو النسخ الاحتياطية. تمنع البوابة بدء عمليات جديدة عند الإيقاف، وتنتظر اكتمال الحفظ الجاري قبل الانتقال إلى صفحة التفعيل. لا تعيد إعادة التفعيل بدء مدة قديمة؛ التجديد الصريح وحده يضيف وقتًا.
