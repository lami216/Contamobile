## الحفاظ على الهاتف

لم تتغير ملفات CSS أو الصور أو الخطوط المعتمدة، ولا ملفات Java أو هوية أندرويد أو الإصدار أو التوقيع أو بروتوكول التفعيل. الشاشات الجديدة تستخدم عناصر الهاتف القائمة، مع العربية والفرنسية، والليلي والنهاري، وإدخال الأرقام وتحديد القيمة كاملة، وقوائم محدودة الحجم.

بقيت المسودات، والتنقل إلى المصدر دون فتح التعديل، وزوال تمييز السجل بعد فتحه أو مغادرته، والحفظ الذري، وصلاحيات المستخدم، والنسخ المحلي والسيرفر، والاسترجاع والتحكم عن بعد. لم تعد أدوات البيانات التجريبية أو إنشاء التقاص أو سعر الجملة أو أزرار الطباعة أو مواضع الإنشاء التي حُذفت سابقًا.

يشترط المرجع 862 عددًا صحيحًا **لرصيد بداية المنتج**. أبقينا هذا الشرط؛ الكسور اختُبرت عبر الشراء والبيع والتصحيح حيث يسمح المصدر بها.

الترقية إلى مخطط الهاتف 3 إضافية؛ تحفظ لقطة `before-feature-upgrade-862` قبل حفظ الترقية. الأرصدة والمستخدمون والسجل القديم لا تعاد تسويتها من أسعار اليوم. التكلفة المؤقتة فقط تعاد قراءتها من مصدرها. استعادة مخطط جديد ناقص أو مجموع دقيق غير متطابق ترفض قبل استبدال البيانات.

حُفظت كذلك قواعد المستند المرحّل للعرض فقط، ومنع تعديل بيع مرتبط بمرتجع تاريخي، وإمكانية نقل فاتورة الشراء إلى مخزن آخر عند تعديلها مع ثبات مخزن البيع. حركات الأطراف تحتفظ بالكسور، وتعديل التصحيح يحتفظ بالمنتج الأصلي المؤرشف ويعيد إظهاره إذا عاد إليه مخزون.

المستند الجزئي والمرتجع التاريخي المستوردان للعرض والتصدير، مع عرض المدفوع والمتبقي الفعليين؛ لا يضاف مسار إنشاء جديد لهما. استيراد التقاص غير المدعوم يرفض كامل العملية بأمان. لا يدمج حساب موظف متباين بين نسختين؛ تستخدم الاستعادة الكاملة عند نقل ملفه.

## ما لم يجتز بوابة الإصدار بعد

لم تنجز بعد بوابة APK الموقّع والتثبيت الفعلي. جُهّز مسار معزول يبني v35 بالتوقيع الدائم المحفوظ، ويتحقق من البصمة وهوية التطبيق، ثم يثبت فوق APK v27 وv34 الأصليين على أندرويد؛ مع حالات تفعيل مؤقت ودائم، وفحوص فتح بارد وتثبيت متكرر. اختبارات الحفظ تقارن المستخدمين والبيانات والمسودات والنسخ المشفرة والتفعيل وهوية التثبيت قبل التحديث وبعده. نتائج المسار الفعلية مطلوبة قبل قبول النسخة. لم نولد مفتاحًا بديلًا ولم نغير هوية التطبيق.

قبل توزيع نسخة هاتف: تشغيل بيلد المرشح بالتوقيع الدائم، ثم اختبار الترقية المباشرة من APK v34 الأصلي مع تحقق البيانات والمستخدمين والتفعيل، واختبار الكاميرا والملفات ولوحة المفاتيح على أندرويد. يبقى ادعاء المطابقة محصورًا في قواعد العمل والشاشات التي غطتها الأدلة أعلاه حتى إنجاز تلك البوابة.
