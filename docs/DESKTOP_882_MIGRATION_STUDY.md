## سلوك المصدر

المصدر الجديد يفرق بين غياب حقل الملاحظة وبين إفراغه عمدًا. الغياب يحفظ النص الأصلي حرفيًا، مع الرجوع إلى الحركة المالية أو التحويل التاريخي فقط إذا كان الحقل الأصلي غير موجود. القيمةnull أو النص الفارغ يمسحانه، ولا يحييان ملاحظة أقدم. يشمل ذلك الدفع والاستلام للعميل والمورد، والإيداع والسحب وتحويل الحسابات. إلغاء قيد تاريخي يبقي بيانه الأصلي، ولا يستبدله بسبب قيد العكس.

`movementStatement` يأخذ الملاحظة النصية المشذبة قبل الوصف النظامي. النص بيانات مستخدم، ولو طابق كلمة مترجمة. أصل النص يحتفظ بمسافاته في البيانات؛ العرض وحده يشذب الطرفين. تقارير المالية وكشوف الأطراف والعمال، وإخراجPDF/XLSX، تستعمل نفس المعنى؛ بيان مالي قابل للفرز مع بقاء ترتيب رصيد الحركة المحاسبي صحيحًا.

## التكييف للهاتف

الملاحظات تظهر كسطرين داخل الخلية الحالية، مع تفاصيلها الكاملة في المستند والتصدير. لا عمود يوسّع الهاتف ولا تغيير للألوان أو الخطوط أو الحدود. بقيت حدود إدخال الملاحظة المعتمدة للهاتف؛ النصوص التاريخية الأطول محفوظة دون قص وإعادة كتابة. الورقة التي يفشل حفظها تحتفظ بالمبلغ والنص لمحاولة صريحة، ويُلغى الاحتفاظ عند إغلاقها أو تغيير صاحب الجلسة/المسار.

المصدر المالي المستورد محفوظ مستقلًا؛ عرضه يستعمل بيانه الحالي لكل طرف من التحويل، بما في ذلك تشابه أسماء الحسابات وانقسام الطرفين عند حد الصفحة50. بعد تعديل محلي تصبح بيانات القيد المعدل هي المعتمدة. العرض يبني فهرسًا مرة واحدة بدل البحث الكامل داخل كل صف. أُصلح غياب التحويلات الواردة من سجل حساب المستقبل، دون تغيير رصيده.

## البيانات والحماية

مخطط الهاتف باقٍ4. لا إعادة حساب للأرصدة أو ترقيم قديم أو تغيير تفعيل أو حذف مسودات. الاستيراد الجديد يحفظ الفرق بين حقل مفقود وnull والنص الحرفي؛ نسخ37 ذات الإسقاط القديم تُقرأ من أصلها غير المعدل دون ترحيل مالي عند الفتح.

حركات البنك اليدوية التاريخية التي لا يرافقها مستند تصبح قابلة للتعديل فقط بإثبات المصدر الأصلي: قيد واحد فعال غير عكسي، وهوية وتاريخ وحساب ومبلغ واتجاه متطابقة، وسجل نسخ متماسك. تبقى أرصدة البداية والقيود المعكوسة والمصادر الملتبسة محمية. لا توسيع للصلاحيات. يبقى المصدر القديم وسجل التعديلات محفوظين.

طلبات الحذف السابقة نافذة: لا تقاص أو جملة أو بيانات تجريبية أو طباعة أو أزرار كمية أو نقاط إنشاء مكررة. لا تعديل للسيرفر أو كونتا تولز. تشغيل قاعدة مشتركة مباشرة أو مزامنة بين الهاتف والجهاز لم يُفعّل.
